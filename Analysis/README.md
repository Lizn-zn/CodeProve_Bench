# CodeVerifBenchmark Analysis Tools

> *This documentation was generated by Cursor AI.*

This directory contains tools for analyzing all problems in the CodeVerifBenchmark.

## Features

Provides three analysis scripts:

### 1. `analyze_sample.py` - Quick Sampling Analysis (Recommended to run first)

Samples a small number of files from each category (LeetCode, CodeExercises, Syn, CodeNet) for quick analysis.

- Default: 30 files per category
- Fast analysis (approximately 2-5 minutes)
- Suitable for quick preview

### 2. `analyze_benchmark.py` - Complete Analysis

Analyzes all problems and generates detailed reports:

1. **Recursion/Loop Analysis**
   - Count how many problems use recursion/loops
   - Distinguish between regular recursion and partial functions
   - List all recursive and non-recursive problems

2. **Init Library Dependency Analysis**
   - Count all Init library dependencies used by problems
   - Show usage frequency of each dependency
   - List specific dependencies used by each problem

### 3. `test_analyze.py` - Test Script

Tests a few specific files to verify the analysis tools are working correctly.

The script generates two report files in the `Analysis/` directory:

### 1. `analysis_report.txt`

Detailed report in text format, including:
- Recursion/loop statistics
- List of recursive problems
- List of non-recursive problems
- Init dependency statistics
- Usage frequency of each Init dependency
- Detailed dependency list for each problem

## How It Works

The script uses tools from the Tools directory:

1. **Recursion Check**: Calls `lake exe check-rec <file>`
   - Check direct recursion (function calls itself)
   - Check mutual recursion (functions call each other)
   - Check partial functions

2. **Dependency Check**: Calls `lake exe check-deps <file>`
   - Extract dependencies from Init core library
   - Count dependency usage
